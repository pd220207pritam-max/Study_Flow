# StudyFlow – Student Study Planner

A responsive student study planner built using HTML, CSS and JavaScript.

## Features

- Task management
- Subject management
- Study schedule
- Pomodoro timer
- Progress tracking
- Dark/Light mode
- Local data storage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
